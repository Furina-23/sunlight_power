# 阳光动力

Minecraft 1.20.1 Fabric 太阳能发电模组。

Mod ID：`sunlight_power`

作者：`Furina-23`

## 开发环境

Minecraft 1.20.1、Fabric Loader 0.19.5、Fabric API 0.92.12、Java 17。

## 构建

```text
./gradlew build
```
